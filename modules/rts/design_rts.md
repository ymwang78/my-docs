# RTS设计

- RTS设计为一个独立的模块，平台通过xRtsInterface调用RTS模块的功能，RTS模块通过xRtsCallbackInterface回调平台的功能。
- 一个平台有多个RTS模块实例, 但同时最多只有一个RTS实例可以运行

## xRtsInterface

- createRtsWidget: 创建RTS Widget，返回一个RTS Widget的句柄。
- destroyRtsWidget: 销毁RTS Widget，释放资源。
- setRtsCallback: 设置RTS回调接口，平台需要实现xRtsCallbackInterface接口，并将其传递给RTS模块。
- exportProject: 导出RTS项目，返回导出结果, 用于平台持久化存储。
- importProject: 导入RTS项目，返回导入结果，用于恢复持久化存储的数据到RTS模块。
- startRts: 启动RTS模块，开始运行RTS实例。
- stopRts: 停止RTS模块，停止运行RTS实例。
- isRtsRunning: 检查RTS模块是否正在运行，返回布尔值。
- resetRts: 重置RTS模块，恢复到初始状态。

## xRtsCallbackInterface

- getFlowSheetInfo: 获取流程图列表(可能有多个流程图)。
- getFlowSheetComputeTask: 获取流程图的计算任务列表。
- setCurrentComputeTask: 设置当前计算任务。
- getMacroInfo: 获取宏信息列表(可能有多个宏)。
- callMacro: 调用宏，执行宏的功能, 注意这里需要携带一个env dict, 用于传递宏执行的环境变量, `__rts_env__` 传入, `__rts_result__` 返回；其中 `__rts_result__` 需直接设置为完整 JSON 对象，例如 `{ "errcode": 0, "errdesc": "ok", "data": {} }`
- solve: 计算RTS实例的结果，返回计算结果。
- appendLog: 追加日志信息，平台可以将日志信息展示给用户。


## rts 内部实现

- rts 按MVC模式设计，model可以脱离view直接运行，view作为观察器和配置器功能存在

- rts 是一个执行流程图，由执行模块(包含输入输出端口)和模块连接线组成

## 1. 实现流程图全局支持功能

- 支持全局变量表, 可以定义能够被各个模块访问的全局变量和初始值

- 支持CSV数据源和OPC数据源定义, 并支持数据源定义的位号绑定, 变量支持和位号关联,

## 2. 实现流程图模块的通用架构和功能:

- 每个模块有多个inport/outport, 除了内置的开始模块(只有outport)和结束模块(只有inport), 一般来说可增加删除

- 每个模块内置一个决策变量(整数值), 根据这个决策变量的值(相等匹配)来决定outport激活

## 3. 内置流程图模块

- 开始模块, 只有一个outport, 没有inport,最主要功能是选择启动模式包括
  - 单次运行
  - 结束后间隔X分钟
  - 首次运行后每X分钟
  - 整点每X小时
  要求:
  - 流程图上能够直观知道当前设置的是哪种模式
  - 当前流程执行结束后, 果会再次运行的话, 开始模块上显示下一次启动时间.
  - 本模块决策变量值永远为0,成功

- 结束模块, 可以设置多个inport,但没有outport, 最主要的功能是表明这次运行是一个符合预期的结束

- Input模块, 可以设置多个inport, 固定2个outport, 最主要的功能是从数据源位号读取数据到变量
  - 根据全局功能里的变量定义, 支持从关联位号自动读入数据到变量, 可以全部读取或者选择一部分读取
  - 本模块的决策变量值选取变量全部读入成功为0, 否则-1

- Output模块, 可以设置多个inport, 固定2个outport, 最主要的功能是把变量数值写入到对应数据源位号
  - 根据全局功能里的变量定义, 支持写入变量到关联位号, 可以全部写入或者选择一部分写入
  - 本模块的决策变量值选取变量全部写入成功为0, 否则-1

- 自定义脚本模块, 可以设置多个inport/outport, 最主要的功能是执行自定义LUA脚本
  - 提供脚本编辑/validate/测试执行功能
  - 本模块的决策变量值由脚本决定,默认是0

- 外部程序调用模块, 可以设置多个inport/outport, 最主要的功能是执行外部程序
  - 提供设置外部执行程序路径/工作路径/执行参数功能
  - 提供同步阻塞等待结束和异步非阻塞发射后不管两种方式
  - 阻塞等待本模块的决策变量值两种选择:1是进程退出代码,2是退出代码是0或者其他情况映射为-1
  - 异步非阻塞变量决策值是调用成功是0, 否则是-1

- 宏模块,  可以设置多个inport, 固定2个outport, 最主要的功能是执行平台提供的宏
  - 提供初始化宏(只第一次执行执行时先执行,通过API获取列表后选择)和执行参数表(名值对, 可从json文件导入)
  - 提供运行宏(每次运行,通过API获取列表后选择)和执行参数表(名值对, 可从json文件导入)
  - 本模块的决策变量值选取运行成功为0, 否则-1

- 计算任务选择模块, 可以设置多个inport, 固定2个outport, 最主要的功能是选择接下来的计算模块使用哪个平台的计算任务
  - 提供计算任务选择(通过API获取计算任务)
  - 本模块的决策变量值选取运行成功为0, 否则-1

- 求解模块, 可以设置多个inport, 固定2个outport, 最主要的功能是调用平台求解功能
  - 提供求解接口参数配置, 名值对, 值是绑定变量
  - 结果变量设置, 把结果json解析后赋值到对应变量
  - 把值从绑定变量读取后写入求解参数,调用求解,把返回的结果解析后写入对应变量
  - 本模块的决策变量值选取运行成功为0, 否则-1
